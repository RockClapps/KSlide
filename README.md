# KSlide

A simple scrolling window manager emulator for kwin

## Supported Features

- Navigation and window reorganizing hotkeys
- Window tiling toggle
- Explicitly doesn't tile floating windows for easy integration with kwin rules
- Multiple monitors

## Limitations

- Some proper scrolling features
  - Window resizing
  - Changing the size of columns relative
  - Can't stack multiple windows per column
- No animations
- No drag+drop window swapping 
- No mouse resizing support

## Known bugs

- Breaks KDE's panel configuration interface, so you should turn it off while editing
  your dock
